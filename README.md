# Night Out Chicago

Live: **https://nightoutchicago.com**

Also: datenightchicago.app redirects here.

**Snap-card UX:** full-screen cards with CSS `scroll-snap-type: y mandatory` — swipe up for the next card. Sticky vibe / with / night filters stay put. Neighborhood cards show dinner + things-to-do counts from the real catalogs; **Make it a night** hard-cuts into Eat → Then → Backup → Get there cards for that hood and night. Warm Chicago-host copy; no free multi-card scroll.

## Data files
- `neighborhoods.json` — hood reel + vibe categories
- `plans.json` — night corridors (Eat / Then / Backup / transit / don’t)
- `restaurants.json` — Eat catalog (39); matcher enriches or swaps by party, vibe, neighborhood
- `events.json` — scouted things to do (105); preferred for Then when party + hood + night fit
